##linux 登录记录
who：显示当前登录用户及终端信息。
w：显示当前登录用户及其正在执行的任务。
users：列出当前登录的用户名。
last：显示历史登录记录，可通过 -n <数字> 限制条数，-u <用户名> 查看指定用户，-F 显示完整时间，-i 显示 IP 地址 
lastb：查看失败的登录尝试，需要 root 权限。
lastlog：查询每个用户的最后一次登录时间。
ac：统计用户总的登录时间。
sudo > /var/log/wtmp：清空所有记录
/var/log/wtmp：记录所有用户的登录、注销以及系统启动和关机事件，可用 last 命令查看历史登录记录 
/var/log/btmp：记录登录失败的尝试，如密码错误或无效用户，可用 lastb 命令查看 
/var/log/lastlog：记录每个用户的最后一次登录时间，可用 lastlog 命令查询 
/var/log/secure 或 auth.log：记录认证相关信息，包括 SSH 登录和可疑 IP 登录次数

【！！！注意！！！】
Ubuntu 无人值守更新升级 libssl/openssl/libc 这类核心库，
会触发动态库热替换，强制回收依赖进程，进程被内核直接强制终止。
解决方案一：禁止自动更新 底层 ssl/libc 核心库（最小影响）
  sudo nano /etc/apt/apt.conf.d/50unattended-upgrades
  在 Unattended-Upgrade::Package-Blacklist 大括号内添加：
	"libssl*";
	"openssl*";
	"libc-bin";
	"libc6*";
	
    "zlib*";
    "libgcc*";
    "libstdc++*";
  保存退出：Ctrl+O → 回车 → Ctrl+X
解决方案二：关闭无人值守自动更新（彻底杜绝，高危漏洞需手动定期执行 apt update && apt upgrade）
  sudo dpkg-reconfigure -plow unattended-upgrades
  在弹出的对话框选择 <No> ，回车确认，关闭自动更新。

#参数详解（性能控制重点）
nice -n 19
##Linux CPU 最低优先级 (19)，系统繁忙时自动让出 CPU，不抢占业务进程
#ionice -c 2 -n 7
##IO 调度优先级最低，磁盘读写礼让其他程序；
##-c2 普通调度，-n7 最低等级；不要用 - c3 空闲 IO，部分内核不稳定
tar -zcf
tar -Jcf
##-J xz 更高压缩率，更耗CPU；-z gzip 快速压缩；c 创建包；v verbose 显示详细打包文件列表（打印正在打包的文件）；f file 指定输出文件,必须放在最后
-C /home/deploy/projectname .
##切换目录到 /home/deploy/projectname，打包目录内所有内容（不把外层文件夹路径打进压缩包）
##如果写成 tar -zcf xxx.tar.gz /home/deploy/projectname,压缩包内顶层是/home/deploy/projectname；

##搭配 nohup + & 后台运行（避免 ssh 断开中断任务），输出日志方便排查：

i -- 切换到输入模式，在光标当前位置开始输入文本。
x -- 删除当前光标所在处的字符。
: -- 切换到底线命令模式，以在最底一行输入命令。
a -- 进入插入模式，在光标下一个位置开始输入文本。
o：在当前行的下方插入一个新行，并进入插入模式。
O -- 在当前行的上方插入一个新行，并进入插入模式。
dd -- 剪切当前行。
yy -- 复制当前行。
p（小写） -- 粘贴剪贴板内容到光标下方。
P（大写）-- 粘贴剪贴板内容到光标上方。
u -- 撤销上一次操作。
Ctrl + r -- 重做上一次撤销的操作。
esc：退出编辑
:w
:w 保存文件但不退出vi 
:w file 将修改另外保存到file中，不退出vi
:w! 强制保存，不推出vi
:wq 保存文件并退出vi
:wq! 强制保存文件，并退出vi
:q 不保存文件，退出vi
:q! 不保存文件，强制退出vi
:e! 放弃所有修改，从上次保存文件开始再编辑命令历史
